These hints describe the typed record vertices built from the structured blocks in the documents.
- Each record has name and doc_title, which hold the full title of the thing it describes. The title often contains words that the separate fields do not, so when the question names a specific thing, match it with toLower(r.name) CONTAINS a lowercase keyword, using one keyword per condition rather than the whole phrase.
- Text fields hold short raw values like the examples below. Match them with CONTAINS on short keywords, never with a long phrase copied from the question.
- For comparisons, counts and rankings on numbers, use the attributes ending in _num (DOUBLE). For years, use the attributes ending in _year (INT). A value of 0 in these attributes means the value is missing.
- For "how many" and "which had the most" questions, return one row per matching record with its name, its doc_id and the attributes involved (for example RETURN r.name AS record_name, r.doc_id AS doc_id, r.x_num AS x_value ORDER BY x_value DESC), and do not use count(). The rows are counted or ranked afterwards, and they show the evidence.

When does a question need an agent?

Pipelines on the same 100 questions

Accuracy is graded by exact match, then an LLM judge for near-matches. Tokens include LLM input, output and query embeddings. Tokens per correct answer divides total tokens by accuracy.

TigerGraph service tokens are the LLM input and output tokens it reports; it does not report embedding tokens. Its answers are full sentences, so exact match understates it; accuracy uses the LLM judge.

Where the gap opens

Accuracy and cost by question type. Lookups are easy for every pipeline; counting and "most competitors" questions need a scan of every event, which similarity retrieval cannot do.

Verdict by question type

An agent is required when no single-pass pipeline reaches 90% accuracy. It is optional when a single retrieval already answers reliably, so the extra planning buys little.

How the agent investigates

The orchestrator chooses tools per question. Deterministic agents (entity linking, traversal, aggregation) cost no LLM tokens; the LLM is spent on planning and, only when grounding fails, on evidence evaluation.
